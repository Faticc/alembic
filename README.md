# Alembic

Алхимический фабричный тайкун на Rust с собственным мини-движком. Все спрайты рисуются
кодом при запуске, звуки синтезируются на лету — готовых ассетов в репозитории нет.

Качай эссенции четырёх стихий из жил, вези их конвейерами в лавку, смешивай, очищай и
перерабатывай: 390 видов предметов, 39 построек, 21 контракт, кооператив через Steam.

## Установка

Скачай `AlembicSetup.exe` со страницы [релизов](https://github.com/Faticc/alembic/releases/latest)
и запусти. Нужна 64-битная Windows 10 или 11. Файл не подписан, поэтому SmartScreen
спросит подтверждение: «Подробнее» → «Выполнить в любом случае».

Дальше игра обновляется сама: при запуске проверяет последний релиз, скачивает новый
`alembic.exe` и ставит его при выходе (или сразу по `F5`). Сохранение не затрагивается.
Отключить проверку можно ключом `--no-update`.

## Управление

| Клавиша | Действие |
| --- | --- |
| `Tab`, `1`–`9`, `0` | вкладка построек, постройка на вкладке |
| Мышь 4 / 5 | предыдущая / следующая постройка |
| ЛКМ, ПКМ | строить (конвейер тянется мышью), снести |
| `R`, `Q` | повернуть, взять постройку под курсором |
| `U` | улучшить машину под курсором |
| `Shift` + ЛКМ | выделить рамкой |
| `Del`, `Ctrl+C` / `X` / `V` | снести выделенное, копия / перенос / вставка |
| `C`, `P` | каталог предметов, путь контракта |
| `F2` | сетевая игра через Steam |
| `WASD`, колесо | камера, масштаб |
| `M`, `F1` | звук, справка |

## Сетевая игра

Кооператив идёт через Steam с тестовым AppID 480 (Spacewar): у обоих игроков должен быть
запущен Steam. Хост жмёт `F2` → «Создать комнату», гость — `F2` → «Найти комнаты».
Мир, деньги и контракты общие, решения принимает хост.

## Сборка из исходников

Нужен Rust с тулчейном `x86_64-pc-windows-gnu`.

```bash
cargo run --release
```

Полезные режимы: `--new` (новая игра), `--screenshot <png>` (кадр демо-фабрики без окна),
`--export-assets <png>` (атлас спрайтов), `--checksave <файл>` (проверить сохранение).

Выпуск новой версии: поднять `version` в `Cargo.toml` и запустить `scripts/release.sh` —
он соберёт игру и установщик и опубликует релиз, который подтянут все установленные копии.

## Устройство

- `src/engine` — движок: программный рендер, растровый шрифт с кириллицей, синтезатор, PNG.
- `src/assets.rs` — процедурные спрайты.
- `src/world.rs` — симуляция, экономика, таблицы построек и предметов, сохранение.
- `src/game.rs` — ввод, интерфейс, отрисовка.
- `src/net.rs` — кооператив через Steam.
- `src/update.rs` — автообновление.
- `installer` — установщик одним файлом.
