# Alembic

Алхимический фабричный тайкун на Rust с собственным мини-движком. Все спрайты рисуются
кодом при запуске, звуки синтезируются на лету — готовых ассетов в репозитории нет.

Качай эссенции четырёх стихий из жил, вези их конвейерами в лавку, смешивай, очищай и
перерабатывай: 1170 позиций каталога (390 видов предметов в трёх чистотах), 62 постройки
и детали логики, 21 контракт, кооператив через Steam.

## Что нового в 0.6

- **Таинства и логистика.** Алтарь с аурами стихий, тигель, трансмутатор, атанор, упаковщик, телепорт,
  переключатель, делитель с пропорцией, фильтры по условию, каталог с чистотой.
- **Слой сигналов** (`L`, вкладка «ЛОГИКА»). Провода, датчики затора, склада и предмета,
  таймер, вентили И / ИЛИ / НЕ, защёлка, счётчик и исполнитель: ворота на ленте, останов
  машины, выбор выхода переключателя. Детали стоят поверх построек и клеток не занимают;
  состояние схемы пишется в сохранение.
- **Насыщение рынка.** Чем больше одной позиции продано недавно, тем она дешевле (до 25%
  цены), со временем цена возвращается. Фабрика «всего понемногу» выгоднее одной линии.
- **Гильдии четырёх стихий** (`G`). Срочные заказы на выбор из трёх, репутация и награды:
  скин лент, жила чистоты II, гильдейская лавка.
- **Великое Делание и новый виток** (`V`). Сдать по одной штуке каждой позиции каталога —
  витраж заполняется по мере сдачи. Сброс фабрики за философские камни даёт постоянные бонусы.
- **Карта.** В новых играх есть преграды (снос за деньги) и разломы с жилами чистоты II.
  Карта старых сохранений не меняется.
- **Библиотека чертежей** (`B`). Скопированный участок фабрики вместе со схемой логики
  сохраняется под именем в `alembic_blueprints.txt` и годится для любой игры.
- **Достижения** Steam.

## Установка

Скачай `AlembicSetup.exe` со страницы [релизов](https://github.com/Faticc/alembic/releases/latest)
и запусти. Нужна 64-битная Windows 10 или 11. Файл не подписан, поэтому SmartScreen
спросит подтверждение: «Подробнее» → «Выполнить в любом случае».

Дальше игра обновляется сама: при запуске проверяет последний релиз, скачивает новый
`alembic.exe` и ставит его при выходе (или сразу по `F5`). Сохранение не затрагивается.
Отключить проверку можно ключом `--no-update`.

## Управление

| Клавиша | Действие |
| --- | --- |
| `Tab`, `1`–`9`, `0` | вкладка построек, постройка на вкладке |
| Мышь 4 / 5 | предыдущая / следующая постройка |
| ЛКМ, ПКМ | строить (конвейер тянется мышью), снести |
| `R`, `Q` | повернуть, взять постройку под курсором |
| `U` | улучшить машину под курсором |
| `Shift` + ЛКМ | выделить рамкой |
| `Del`, `Ctrl+C` / `X` / `V` | снести выделенное, копия / перенос / вставка (вместе с логикой) |
| `B` | библиотека чертежей: сохранить буфер под именем, взять чертёж |
| `E`, `F` | настройка постройки или детали логики, сброс образца фильтра |
| `L` | слой проводов логики |
| `G`, `V` | гильдии и заказы, витраж Великого Делания и новый виток |
| `C`, `T`, `P` | каталог предметов, статистика продаж, путь контракта |
| `F2` | сетевая игра через Steam |
| `WASD`, колесо | камера, масштаб |
| `M`, `F1` | звук, справка |
| `F3` | счётчик FPS (в сетевой игре — и пинг) |
| `F11`, `Alt+Enter` | полноэкранный режим |

## Сетевая игра

Кооператив идёт через Steam с тестовым AppID 480 (Spacewar): у обоих игроков должен быть
запущен Steam. Хост жмёт `F2` → «Создать комнату», гость — `F2` → «Найти комнаты».
Мир, деньги и контракты общие, решения принимает хост: цены рынка, гильдии, мегапроект
и состояние сигналов клиент получает от него. Библиотека чертежей у каждого игрока своя.

## Сборка из исходников

Нужен Rust с тулчейном `x86_64-pc-windows-gnu`.

```bash
cargo run --release
```

Полезные режимы: `--new` (новая игра), `--screenshot <png>` (кадр демо-фабрики без окна),
`--export-assets <png>` (атлас спрайтов), `--checksave <файл>` (проверить сохранение).

Выпуск новой версии: поднять `version` в `Cargo.toml` и запустить `scripts/release.sh` —
он соберёт игру и установщик и опубликует релиз, который подтянут все установленные копии.

## Устройство

- `src/engine` — движок: программный рендер, растровый шрифт с кириллицей, синтезатор, PNG.
- `src/assets.rs` — процедурные спрайты.
- `src/world.rs` — симуляция, экономика, таблицы построек и предметов, сохранение.
- `src/game.rs` — ввод, интерфейс, отрисовка.
- `src/net.rs` — кооператив через Steam.
- `src/update.rs` — автообновление.
- `installer` — установщик одним файлом.
